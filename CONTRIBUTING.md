# Разработка Model Anvi

Перед изменениями прочитай [AGENTS.md](AGENTS.md) и [ARCHITECTURE.md](ARCHITECTURE.md).

## Окружение

Рабочая платформа — Windows, Python 3.10+ с Tkinter. Из корня репозитория:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Для ручного запуска нужен локальный сервер Ollama с настроенным тегом модели:

```powershell
.\.venv\Scripts\python.exe local_chat.pyw
```

Для тестов и документационного предпросмотра Ollama не нужна.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -v -p "test_*.py"
git diff --check
```

| Область | Что проверить |
| --- | --- |
| Вывод и анализ | Отмену, задержанные события, лимит контекста, прерывание потока и отметки неполного результата. |
| Вложения | Формат, размер, повторный вопрос по сохранённой копии, уведомления о сокращении, сохранность оригинала. |
| SQLite и очистка | Открытие старой БД, каскады, сохранение отчётов; использовать только временные данные. |
| Интерфейс | Читаемость на минимальном размере окна, фокус ввода, кнопки, Markdown и Ctrl+Enter. |
| `.cmd` | Путь с пробелами/кириллицей, существующую и новую `.venv`, код возврата при ошибке. |
| Документация | Соответствие коду, рабочие относительные ссылки и изображения. |

CI в `.github/workflows/tests.yml` запускает существующие `unittest` на Windows
с Python 3.10. Проверки используют подменённые ответы Ollama. Проверка настоящей
модели — отдельный ручной сценарий: фиксируй тег, оборудование, контекст и запрос.
Не выдавай прохождение unit-тестов за проверку качества или скорости модели.

## Снимки для README

`tools/preview_docs.py` импортирует настоящий `LocalChat`, создаёт временную
историю с заранее подготовленными примерами и отключает сетевые операции
и удаление данных в этом экземпляре. Реальная история пользователя не открывается.

Для интерактивного предпросмотра:

```powershell
.\.venv\Scripts\python.exe tools/preview_docs.py --scene chat
```

Для обновления PNG на Windows:

```powershell
.\.venv\Scripts\python.exe tools/preview_docs.py --scene chat --output docs/images/chat.png
.\.venv\Scripts\python.exe tools/preview_docs.py --scene code --output docs/images/code-review.png
```

Снимки получаются из окна Tkinter через Pillow. После обновления открой каждую
картинку и проверь, что текст, кнопки и поля полностью видны. Сохраняй подпись
о демонстрационных ответах; этот инструмент не запускает модель и не делает
замеры производительности.

## Git и описание изменений

Создавай отдельную ветку для самостоятельной задачи, например `docs/readme`
или `fix/stop-request`. Пиши небольшие понятные коммиты: `docs: ...`, `fix: ...`,
`feat: ...`, `ci: ...`, `chore: ...`. Перед отправкой проверь:

```powershell
git status --short
git diff --cached --stat
git diff --cached --check
```

В описании PR укажи исходную проблему, итоговое поведение, выполненные проверки
и ограничения. Если менялись форматы, лимиты, настройки или схема хранения,
обнови README и соответствующий архитектурный документ.

В коммит входят исходники, документация, демонстрационные PNG и настройки
проверок. Данные исполнения, личные файлы и модельные веса исключаются через
`.gitignore`. Правила окончаний строк задаёт `.gitattributes`, оформление
текстовых файлов — `.editorconfig`.
