# Установка NeuroQuay и устранение проблем

[Назад к README](../README.md)

## Обычная установка Ollama

1. Установи Python 3.10+ с Tcl/Tk и добавлением в `PATH`.
2. Установи [Ollama для Windows](https://ollama.com/download/windows).
3. В PowerShell выполни `ollama pull qwen3.8:27b-q4_K_M`.
4. Скачай репозиторий, открой его папку, запусти `Установить зависимости.cmd`.
5. Запусти `Запустить чат.cmd`. Установленная Ollama должна работать в фоне.

Приложение использует уже работающий сервер на `127.0.0.1:11434`. В этом режиме
модели хранятся по настройкам этого сервера, обычно в `%USERPROFILE%\.ollama\models`.
Если меняешь каталог через `OLLAMA_MODELS`, перезапусти Ollama:
[инструкция Ollama для Windows](https://docs.ollama.com/windows).

При первом запуске интернет нужен для библиотек и весов. После их установки
локальная модель может работать без интернет-соединения.

## Установка вручную из PowerShell

Из папки с `local_chat.pyw`:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe local_chat.pyw
```

Это не требует активации `.venv` или изменения политики выполнения PowerShell.
Последняя команда оставляет консоль с диагностикой. Для повседневного запуска
используй `Запустить чат.cmd`: он открывает окно через `pythonw`.

Если `py` отсутствует, замени первую команду на `python -m venv .venv`;
проверь `python --version`. Установщик `.cmd` сам проверяет Python 3.10+
и наличие Tkinter. При существующей `.venv` он использует её интерпретатор.

## Отдельная установка рядом с проектом

Для уже существующей структуры `LocalLLM/Chat`:

```text
LocalLLM/
├── Chat/               # этот Git-репозиторий
│   ├── local_chat.pyw
│   ├── requirements.txt
│   └── .venv/
├── Ollama/             # распакованная standalone-версия со всеми библиотеками
│   ├── ollama.exe
│   └── lib/
└── models/             # каталог Ollama: blobs/ и manifests/
```

Скачай standalone-архив из [релизов Ollama](https://github.com/ollama/ollama/releases)
и распакуй его полностью в `Ollama/`. Одного `ollama.exe` без библиотек недостаточно
для такого комплекта. Имя папки с исходниками может отличаться от `Chat`;
пути вычисляются от неё.

Если другой сервер на порту 11434 не работает, приложение само запустит
`../Ollama/ollama.exe serve` и настроит его на `../models/`.
Для первоначального скачивания модели в отдельном комплекте открой PowerShell
в `LocalLLM` и запусти сервер:

```powershell
$env:OLLAMA_HOST = "127.0.0.1:11434"
$env:OLLAMA_MODELS = Join-Path (Get-Location) "models"
$env:OLLAMA_NO_CLOUD = "1"
.\Ollama\ollama.exe serve
```

Во втором PowerShell, также в `LocalLLM`, скачай модель:

```powershell
$env:OLLAMA_HOST = "127.0.0.1:11434"
.\Ollama\ollama.exe pull qwen3.8:27b-q4_K_M
.\Ollama\ollama.exe list
```

После скачивания останови сервер в первой консоли через Ctrl+C. Затем запускай
чат: приложение сможет управлять своим процессом Ollama. Модель остаётся
в `models/`; эти файлы не входят в Git-репозиторий.

Настройки памяти/облака приложения применяются только к процессу, который оно
запускает само. Для внешнего сервера задай их отдельно при необходимости;
см. [FAQ Ollama](https://docs.ollama.com/faq).

## Частые проблемы

| Симптом | Что проверить |
| --- | --- |
| Python не найден | `py -3 --version` или `python --version`; установи Python 3.10+ и проверь `PATH`. |
| Ошибка `tkinter` | Установи компонент Tcl/Tk в установщике Python. |
| «Dependencies are not installed» | Запусти `Установить зависимости.cmd` в этой папке или выполни ручные команды выше. |
| Окно не открывается | Запусти `.\.venv\Scripts\python.exe local_chat.pyw` и прочитай ошибку в консоли. |
| Нет подключения к Ollama | Проверь `Invoke-RestMethod http://127.0.0.1:11434/api/version`. Для отдельного комплекта проверь `../Ollama/ollama.exe` и `server.log`. |
| `model not found` / HTTP 404 | Убедись, что `ollama list` показывает именно `qwen3.8:27b-q4_K_M` у того сервера, к которому подключён чат. |
| Долго нет текста ответа | Первая генерация загружает веса; в режиме рассуждения текст появляется после thinking. Проверь статус, попробуй «Выкл» и короткий вопрос. |
| Не хватает памяти | Уменьши глубину и объём вложений. Проверяй состояние через `ollama ps`; другая модель требует адаптации текущих настроек. |
| Ответ оборван лимитом | Выбери больший бюджет или сузь вопрос; учти, что рассуждение тоже расходует токены. |
| Большой PDF/проект отклонён | Раздели документ или выбери меньшую папку/один исходник. Лимиты перечислены в README. |
| Не удаётся выгрузить модель | Дождись фонового запроса и проверь, не использует ли тот же сервер другое приложение. |

Для диагностики не публикуй `history.sqlite3`, вложения и полный `server.log`:
достаточно текста ошибки без пользовательских данных.
