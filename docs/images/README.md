# Снимки интерфейса

- `chat.png` — история, Markdown, настройки рассуждения и ожидающее отправки вложение.
- `code-review.png` — пример пояснения ошибки в Python-файле и предложения исправления.

Снимки показывают реальные виджеты `LocalChat` на Windows. История создана
специально для документации. Текст ответов написан заранее; вывод модели,
производительность и точность анализа этими изображениями не подтверждаются.

Источник примеров и способ получения: [`tools/preview_docs.py`](../../tools/preview_docs.py).
Команды обновления — в [CONTRIBUTING.md](../../CONTRIBUTING.md).
