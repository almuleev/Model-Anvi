# Локальный чат Qwen

## Запуск

1. Один раз запустите `Установить зависимости.cmd`. Он создаст `.venv` в этой папке и установит библиотеки из `requirements.txt`.
2. Запустите `Запустить чат.cmd`.

Обычные текстовые сообщения не требуют обработки файлов. Для вложений нажмите **«Прикрепить…»**, выберите до пяти файлов, при желании напишите вопрос и нажмите **«Отправить»**. Выбранный файл можно убрать до отправки. Сообщение без текста отправится с вопросом «Опиши содержимое вложений».

Поддерживаются изображения JPG, PNG, WebP, BMP и TIFF, текстовые файлы TXT, MD, CSV, JSON, PY и LOG, документы PDF, DOCX, XLSX и PPTX. Один файл — до 25 МБ. PDF может содержать до 100 страниц; если более 12 страниц не имеют текстового слоя, разделите его на части. В одном запросе модель получает не более пяти изображений; при превышении приложение отмечает неполный охват.

Файлы копируются в локальную папку `attachments` и остаются доступны для последующих вопросов в этом чате, даже если исходник перемещён. Для длинного документа приложение выбирает относящиеся к вопросу фрагменты; при просьбе о полной сводке последовательно сокращает части документа. В ответе следует учитывать уведомления о неполном охвате.

Удаление чата удаляет его локальные копии вложений. Команда **«Удалить все данные»** удаляет все копии вложений вместе с историей. Исходные файлы не изменяются.
